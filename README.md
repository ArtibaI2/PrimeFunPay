# 🤖 FunPay Bot — Автоматизация торговли на FunPay

Многофункциональный асинхронный бот для торговой площадки [FunPay](https://funpay.com/) с автовыдачей цифровых товаров, автоподнятием лотов, автоответами и полным контролем через **Telegram**.

---

## ✨ Возможности

- ⚡ **Автовыдача товаров:** мгновенная отправка ключей, аккаунтов или ссылок сразу после оплаты с настраиваемыми шаблонами выдачи.
- 🚀 **Автоподнятие лотов:** периодический подъем предложений по всем категориям с безопасными интервалами.
- 💬 **Прямой Чат-центр в Telegram:** пересылка сообщений покупателей в Telegram и возможность моментально ответить покупателю прямо через обычный Reply в Telegram.
- 🤖 **FAQ Автоответчик:** настраиваемая база шаблонов автоответов на частые вопросы с редактором прямо в Telegram.
- 📦 **Управление складом через Telegram:** пополнение отправкой `.txt` файлов или сообщений, индикаторы наличия и очистка.
- 📊 **Финансовая аналитика:** статистика за сегодня, 7 дней, 30 дней, всё время, средний чек и топ продаваемых товаров.
- 🎯 **Смарт-цена (Smart Pricing):** автоматический мониторинг конкурентов и расчет оптимальных цен.
- 🔔 **Уведомления:** моментальные оповещения о заказах, сообщениях покупателей и изменениях баланса.
- 🛡️ **Безопасность:** поддержка HTTP/SOCKS5 прокси, кастомный User-Agent, защищенные запросы.
- 💾 **База данных:** SQLite с поддержкой асинхронного доступа (`SQLAlchemy 2.0` + `aiosqlite`).

## 🚀 Установка и запуск

### 1. Клонирование и установка зависимостей

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация окружения (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка конфигурации (.env)

Скопируйте файл `.env.example` в `.env`:
```bash
copy .env.example .env
```

Заполните ключевые параметры в `.env`:

1. **`FUNPAY_GOLDEN_KEY`**: значение cookie `golden_key` вашего аккаунта FunPay:
   - Откройте браузер, перейдите на [funpay.com](https://funpay.com/) и войдите в аккаунт.
   - Нажмите `F12` (Инструменты разработчика) -> вкладка **Application** (или **Хранилище**) -> **Cookies** -> `https://funpay.com`.
   - Скопируйте значение параметра `golden_key` (длинная строка из 32 символов).
2. **`TELEGRAM_BOT_TOKEN`**: токен Telegram-бота от [@BotFather](https://t.me/BotFather).
3. **`TELEGRAM_ADMIN_IDS`**: ваш Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot)).

### 3. Запуск бота

```bash
python main.py
```

## 📦 Способы загрузки товаров на склад

### Способ 1: Через Telegram-бота
- Отправьте команду `/addstock` в диалоге с ботом в Telegram.
- Введите название категории/лота и отправьте список ключей (каждый ключ с новой строки).

### Способ 2: Через текстовые файлы
- Поместите файл `stock.txt` (или `<название_лота>.txt`) в папку `storage/goods/`.
- Каждая строка будет выдаваться по порядку и автоматически удаляться из файла после успешной выдачи.
