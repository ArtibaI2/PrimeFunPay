# 🚀 Руководство по установке, регистрации ключей и хостингу FunPay Bot 24/7

Данное руководство описывает, как настроить все необходимые ключи и запустить бота на постоянную работу (24/7) на домашнем ПК или удаленном сервере (VPS).

---

## 🔑 Необходимые ключи и данные

| Параметр | Обязателен? | Где взять / Как получить | Описание |
| :--- | :---: | :--- | :--- |
| **`FUNPAY_GOLDEN_KEY`** | **ДА** | Браузер -> FunPay -> `F12` -> Вкладка *Application/Память* -> *Cookies* -> `golden_key` | Ваш 32-значный токен авторизации на FunPay |
| **`TELEGRAM_BOT_TOKEN`**| **ДА** *(для TG)* | Telegram: бот [@BotFather](https://t.me/BotFather) -> команда `/newbot` | Токен управления ботом через Telegram |
| **`TELEGRAM_ADMIN_IDS`** | **ДА** *(для TG)* | Telegram: бот [@userinfobot](https://t.me/userinfobot) | Ваш цифровой Telegram ID (доступ к админке) |
| **`AI_API_KEY`** | **НЕТ** *(Опционально)*| OpenAI / OpenRouter / DeepSeek / Gemini | Ключ нейросети для умных автоответов покупателям. **Без него бот полностью работает**, отвечая по правилам и шаблонам, а функции с AI отключаются |
| **`FUNPAY_PROXY`** | **НЕТ** *(Опционально)*| Любой сервис прокси (HTTP / SOCKS5) | Прокси вида `http://user:pass@ip:port` для работы на зарубежных VPS |

## ⚡ Быстрая первоначальная настройка (Мастер ключей)

Запустите интерактивный мастер, который запросит все ключи с подсказками, **автоматически проверит их работоспособность в реальном времени** и создаст файл `.env`:

### На Windows:
```cmd
.venv\Scripts\python setup_wizard.py
```
*(Или запустите `setup.bat`)*

### На Linux / VPS:
```bash
python3 setup_wizard.py
```

## 🌐 Варианты хостинга 24/7

### Вариант 1: Развертывание через Docker (Рекомендуемый)

Docker гарантирует изолированную и стабильную работу бота на любом сервере без конфликтов версий.

1. **Установите Docker и Docker Compose** на ваш сервер:
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
2. **Склонируйте или загрузите проект на сервер:**
   ```bash
   git clone <ваш_репозиторий> /root/FunPayBot
   cd /root/FunPayBot
   ```
3. **Настройте ключи:**
   ```bash
   python3 setup_wizard.py
   ```
4. **Запустите контейнер:**
   ```bash
   docker compose up -d --build
   ```
5. **Просмотр логов в реальном времени:**
   ```bash
   docker compose logs -f
   ```

---

### Вариант 2: Автоматический запуск на Ubuntu / Debian VPS (через 1-Click скрипт)

1. Подключитесь к VPS по SSH:
   ```bash
   ssh root@ip_вашего_сервера
   ```
2. Перейдите в папку проекта и запустите:
   ```bash
   sudo bash deploy.sh
   ```
3. Скрипт сам установит Python, настроит службу `systemd` с автозапуском при перезагрузке сервера и запустит бота!

**Команды управления службой:**
- Статус: `systemctl status funpaybot`
- Логи: `journalctl -u funpaybot -f`
- Перезапуск: `systemctl restart funpaybot`
- Остановка: `systemctl stop funpaybot`

---

### Вариант 3: Запуск на локальном ПК / Windows Server

1. Запустите файл `setup.bat` (установит окружение и запустит мастер ввода ключей).
2. Запустите файл `start.bat` (запустит бота в фоновом режиме).

## 📱 Доступ к Web-панели (Dashboard)

После запуска Web-панель доступна по адресу:
- Локально: `http://localhost:8080`
- На сервере: `http://IP_ВАШЕГО_СЕРВЕРА:8080`

### Подключение Telegram WebApp (по HTTPS):
Если вы хотите открывать WebApp прямо внутри Telegram:
1. Запустите бесплатный туннель (например, Cloudflare Tunnel или ngrok):
   ```bash
   cloudflared tunnel --url http://localhost:8080
   ```
2. Вставьте полученный `https://xxxx.trycloudflare.com` в параметр `WEBAPP_URL` в `.env`.

## 💾 Сохранение данных и резервное копирование

Вся база данных заказов, лотов, шаблонов и логов хранится в папке:
- `storage/sqlite.db` — База данных
- `storage/logs/` — Логи
- `storage/goods/` — Файлы товаров и ключи

При работе через Docker папка `./storage` примонтирована на диск хоста, поэтому ваши данные никогда не потеряются при перезапуске или обновлении контейнера!
